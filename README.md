README Reflection – C++ Course Project
Reflection: README — C++ Course Project

It was a project which catered my skills on designing and building a concrete C++ application to solve an real world application using OOP, data structures as well as C++ programming best practices. The purpose of the program was to fulfill the project specifications and provide a facility for users to a well-structured, functional, and efficient solution while adhering to undefined but clear readable code.

The best part of this project was to segregate the code into proper functions and classes for easy readability, testing and maintainability. I also used code formatting meaningful variable names and comments to make it easy for another programmer to get the gist of what each part was doing. I also made sure that the program satisfied all project requirements while yielding correct and reliable results.

The program runs but there are some notable improvements that can be made. I could add even more input validation to help the program handle unexpected user input more gracefully and avoid run time errors. I could make things more efficient by optimising some of these algorithms and taking out a lot of repeated code. Making the application more secure, fault tolerant and scalable when used in a wider domain by adding error handling logic and further testing.

The hardest thing in this project was to divide the entire Problem into well-defined functions which can work and cooperate together. Some logic bugs were able to be debugged and, if compiling properly, you know I was trying. When I encountered issues, I used debug mode, read compiler error messages and fetched answers from course materials or C++ documentation. The confidence I gained in solving these introduced problems, and how they emphasized the importance of testing throughout development.

This project developed many skills that have direct transferability to future coursework as well as software development projects. Among them are object-oriented programming, problem-solving, debugging, modular program design and writing clean maintainable code. Learned how to version control with GitHub, a must when working on software projects in professional environments.

I wrote this program for maintainability, creating different functions for the main responsibilities and using descriptive variable/function names. Uniform structure and commenting increase readability, which helps the code base be more comprehensible to other team members. Program is adaptive as modular structure makes it easy for any new features or changes to be introduced into the program without having to change too much of the existing code. By following these programming practices, you will ensure that the software can be easily updated and maintained.
